9. RECOMMENDATION ENGINE
==================================================

RecommendationEngine.java is the most important business logic component.

Create a deterministic compatibility scoring system.

Evaluate:

1. Risk compatibility
2. Duration compatibility
3. Goal compatibility
4. Liquidity compatibility
5. Investment style compatibility
6. Experience compatibility
7. Selected category compatibility
8. Regular income compatibility

Calculate an overall compatibility score.

Normalize it to a percentage.

Example:

Index Fund
Risk Compatibility: 90%
Duration Compatibility: 95%
Goal Compatibility: 92%
Liquidity Compatibility: 90%
Overall Match: 92%

IMPORTANT:

The percentage means:

"Compatibility with the user's selected profile."

It does NOT mean:

- Expected return
- Guaranteed return
- Probability of profit
- Guaranteed performance

Return the top 5 compatible investments.

Also allow the user to explore additional investments.
