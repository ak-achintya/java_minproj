INVESTWISE — PRODUCT REQUIREMENTS DOCUMENT (PRD)

1. PRODUCT OVERVIEW
InvestWise is an educational investment exploration platform that helps users understand and explore investment options based on their financial profile, goals, risk tolerance, investment duration, liquidity needs, investment style, and experience.

InvestWise is an educational tool. It does not provide guaranteed returns or personalized financial, tax, or legal advice.

2. CORE OBJECTIVE
Build a simple, modern fintech-style application that:
- Collects a user's investment profile.
- Uses a deterministic recommendation engine to calculate investment compatibility.
- Displays the best matching investment options.
- Explains why an option matches the user's profile.
- Allows users to compare investments.
- Provides an AI educational analysis and chatbot through Gemini.
- Continues working even when Gemini is unavailable.

12. RECOMMENDATION ENGINE
The recommendation engine is deterministic and must be implemented in Java.

It evaluates:
- Risk compatibility
- Duration compatibility
- Goal compatibility
- Liquidity compatibility
- Investment style compatibility
- Experience compatibility
- Selected category compatibility
- Regular income compatibility

Each investment receives a compatibility score.

The score means how compatible an investment is with the selected profile. It must not be represented as expected return or guaranteed performance.

The system should return the top 5 compatible options and allow users to explore additional options.

15. AI ANALYSIS
Gemini is an educational support layer, not the recommendation engine.

AI analysis should explain:
- Why the displayed options match the profile
- Major risks
- Important limitations
- What the user should understand before investing

Gemini must not change the deterministic recommendation score.

16. AI CHATBOT
The chatbot should support questions such as:
- Why did you recommend this?
- Give me more options.
- Compare these two.
- What are the risks?
- Explain this simply.
- What if I increase my investment?
- What if I need the money earlier?
- What does this investment mean?

The chatbot should maintain conversation context during the current session.

- Never commit a real API key to Git.

24. SUCCESS CRITERIA
The MVP is successful when:
- The application starts correctly.
- The frontend communicates with Java.
- User profiles can be submitted.
- Recommendations are generated deterministically.
- At least 5 relevant options can be displayed.
- Investments can be compared.
- Gemini can provide educational analysis when configured.
- The chatbot can maintain session context.
- The application continues working when Gemini is unavailable.
- No API key is exposed to the frontend.
